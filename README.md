## Перевод

Перевод сделан вручную и по смыслу, без машинных переводчиков. Терминология — принятая
парапланерная/парашютная: `gore` → **клин (полотнище)**, `apex` → **вершина купола**, `skirt` →
**нижняя кромка**, `bridle` → **фал**, `comb` → **гребёнка**, `deployment bag / nappy` →
**внутренний контейнер («памперс»)**, `closing loop` → **замыкающая петля**.

Полная таблица терминов: [словарь в русской версии](manual-ru.md#словарь-терминов).

## Если у вас Mayday 18

Ключевые числа, которые нужны при переукладке именно 18-й (всё остальное в мануале общее для серии):

- площадь 30 м², **18 клиньев**, стропы 5150 мм, вес 2,220 кг, снижение 5,4 м/с;
- полётный вес 75–120 кг, сертификация SHV;
- при раскладке по гребёнке — **по 9 строп** с каждой стороны от центральной;
- после «перелистывания» — **9 клиньев слева и 8 справа**, один сверху посередине;
- усилие выхода замыкающей петли: **≤ 400 г** за стропы, **≤ 200 г** напрямую за фал;
- интервал переукладки — **раз в 6 месяцев**.
